## Overview

This project illustrates the basic Git workflow, and benefits of Git in software development workflow.

Git is a distrubuted system which allows the developers to keep track of changes to their files, return to previous version of the project.

## Why Git makes Development Easier

This project demonstrates the basic Git workflow for managing, tracking, and sharing software projects. 

Why Git Makes Development Easier
